# Brand icon sources

Technology and LinkedIn artwork is vendored from [Devicon](https://github.com/devicons/devicon), using the `icons/<name>/<name>-original.svg` variants. Devicon is distributed under the included MIT license (`DEVICON-LICENSE.txt`).

Gmail artwork is vendored from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/gmail.svg), distributed under the included CC0 dedication (`SIMPLE-ICONS-LICENSE.md`).

Original brand artwork is retained inside consistent light-background tiles for readability on GitHub light and dark themes. Social buttons follow the logo-and-label pattern in [Rafaella Ballerini's profile](https://github.com/rafaballerini/rafaballerini/blob/main/README.md).

`scripts/generate_labels.py` builds the profile-ready SVGs in `assets/skills` and `assets/contact` from these local source assets. Names and logos identify the technologies and services; no affiliation is implied.
