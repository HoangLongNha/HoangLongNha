## Selected coursework & projects

### [Data Fitting & Ordinary Least Squares](https://github.com/HoangLongNha/ToanUngDung-Lab2)

A mathematical and computational exploration of regression, from the normal
equations to model diagnostics.

- OLS implementation with NumPy, including the hat matrix and coefficient inference.
- Ridge and Lasso regularization, residual analysis, and k-fold cross-validation.
- Monte Carlo experiments illustrating the Gauss–Markov theorem.

<sub>Python / NumPy / SciPy / Matplotlib · Academic coursework</sub>

### SVD Image Watermarking

A course project applying **singular value decomposition** to image watermarking:
embedding a logo, extracting it, and examining how image transformations affect
recovery quality. The project includes robustness analysis using PSNR, SSIM,
and normalized correlation.

<sub>Python / NumPy / Pillow / Flask · Academic project</sub>

### YouTube Video Data Analysis — in progress

Exploratory analysis of YouTube video metadata, with data integrity checks,
preprocessing, and visualizations of viewing patterns and video characteristics.
The modeling workflow includes Ridge and Random Forest baselines;
training and evaluation are still in progress.

<sub>Python / pandas / Seaborn / scikit-learn · Ongoing coursework</sub>
